# Rotary-Inverted-Pendulum (Furuta Pendulum)

This project includes the SolidWorks model of a Rotary Inverted Pendulum.
It also includes the SimScape block diagram to control the inverted pendulum.
The controller used for it is PID.
You can check out that initially the pendulum is under at stable equilibrium due to gravity acting on it and later it balances itself in some time and after its stabilization I have given a disturbance to it, to which it again overcomes and restabilizes.
