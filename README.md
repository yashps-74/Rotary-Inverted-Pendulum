# Rotary Inverted Pendulum (Furuta Pendulum)
This project includes the SOLIDWORKS model of a Rotary Inverted Pendulum. It also includes the Simscape block diagram to control the inverted pendulum.
The controller used for it is PID.
You can check out that initially the pendulum is upright and two disturbances are given to it first at 0 second and another at 10 second.
A single PID cannot take the pendulum from bottom to upright by its own.
It can only balance it if it is upright and the same thing is shown in this project.
